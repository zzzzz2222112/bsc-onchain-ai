# Model pipeline

`train_sparse.py` uses only Python's standard library. It builds the deterministic sparse model from the checked-in corpus, ontology, and answer lexicon. `train.py` and the `*_experiment.py` files preserve earlier dense-model diagnostics and are not deployment inputs.

```bash
python3 train_sparse.py
```

Generated artifacts:

- `model.bin`: the 514,254-byte sorted feature dictionary containing 13,531 active `uint64` IDs, 27 intent weights, 3 sentiment weights, and biases;
- `model-0.bin` through `model-21.bin`: deployable chunks of the same payload, each below the EIP-170 runtime-code limit;
- `lexicon-zh.bin` and `lexicon-en.bin`: indexed UTF-8 answer blobs;
- `manifest.json`: dimensions, scores, hashes, and truth boundary;
- `vectors.json`: fixed parity vectors used by Solidity tests;
- `sparse-diagnostics.json`: results on exposed development suites; these are regression diagnostics, not independent evidence;
- `release-acceptance-v4.json`: exposed development regression after its failures informed refinement;
- `release-acceptance-v5.json`: one-shot post-freeze independent quality result for the current corpus hash;
- `corpus.sha256`: reproducibility commitment over examples, responses, ontology inputs, and architecture identity.

The current independent v5 suite was written only after corpus SHA-256 `9bd76b2d…ac8e7` and the 13,531-feature model were frozen. It scores 71/81 top-1 (87.65%), 77/81 top-2 (95.06%), 17/18 sentiment (94.44%), and recovers both expected topics in the top two for 8/12 mixed prompts (66.67%; 11/12 in the top three). It passes the declared 80%/90%/85%/60% gates. This is evidence for bounded intent routing, not proof of open-ended reasoning or factual correctness.

The training process is off-chain. It blends a multiclass perceptron with TF/IDF centroids and quantizes the resulting linear heads. Generated bytes are stored as immutable contract runtime code. Solidity independently performs the same UTF-8 tokenisation, FNV-64 feature lookup, int8 score accumulation, follow-up resolution, response lookup, and context hashing.
